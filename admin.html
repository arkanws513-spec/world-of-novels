إدارة الفصول

اختر رواية لعرض فصولها.

يدعم محرّك الموقع العناوين التي تبدأ بـ # و ###، والفقرات، والتغميق باستخدام **النص**.

كيف تنشر التعديلات؟

  1. احفظ بيانات الرواية والفصول في المسودة.
  2. نزّل ملف content/novels.json واستبدل الملف نفسه في المستودع.
  3. نزّل ملفات الفصول الجديدة أو المعدّلة وضع كل ملف في مجلده الصحيح داخل content/novels/.
  4. ارفع التغييرات إلى فرع main. سيقوم GitHub Actions ببناء صفحات القراءة ونشرها تلقائيًا.

لا تحذف ملفات الفصول القديمة يدويًا إلا بعد مراجعة الفهرس؛ محرّك البناء يقرأ ملفات Markdown الموجودة داخل مجلد الرواية.
