# إضافة رواية جديدة تلقائيًا

أصبح محرّك البناء يكتشف ملفات `novel.json` داخل مجلدات `content/novels/` تلقائيًا.

## الطريقة

1. افتح لوحة الإدارة: `/admin.html`، ثم اضغط **رواية جديدة**.
2. املأ العنوان والكاتب والوصف والتصنيفات والمقدمة والغلاف والحالة.
3. اضغط **تجهيز ملف رواية جديدة** لتنزيل `novel.json`.
4. في GitHub أنشئ مجلدًا باسم الرواية داخل `content/novels/`، وارفع ملف `novel.json` داخله.
5. أنشئ مجلد `chapters` بجواره، وضع الفصول داخله بأسماء متسلسلة مثل `001.md` و`002.md`.
6. ارفع الملفات إلى فرع `main`. سيكتشف GitHub Actions الرواية، ويضيفها إلى `content/novels.json` و`catalog.json`، ويبني صفحة الرواية والفصول ويحدّث `sitemap.xml` تلقائيًا.

## مثال لبنية الملفات

```text
content/novels/my-new-novel/
  novel.json
  chapters/
    001.md
    002.md
    003.md
```

## ملاحظات

- اترك `id` فريدًا لكل رواية، ولا تغيّره بعد النشر.
- يجب أن يتضمن `novel.json` على الأقل `id` و`title`. ملف التصدير من لوحة الإدارة يجهز بقية الحقول.
- يبدأ كل فصل بعنوان Markdown مثل `# الفصل الأول — العنوان`، ثم سطر فارغ، ثم نص الفصل.
- لا تعدّل `catalog.json` يدويًا؛ فهو ملف مولّد.
- الإضافة التلقائية تبدأ بعد رفع الملفات إلى GitHub؛ لوحة الإدارة لا ترفع الملفات بنفسها ولا تحتوي على مفاتيح وصول.
