# عالم الروايات — نظام النشر

مكتبة روايات عربية ثابتة وسريعة، تعمل على GitHub Pages دون خادم أو قاعدة بيانات أو مفاتيح API مدفوعة.

## طريقة إضافة فصل جديد

1. افتح مجلد الرواية داخل `content/novels/`.
2. افتح مجلد `chapters`.
3. أضف ملف Markdown برقم متسلسل من ثلاثة أرقام، مثل `031.md`.
4. اجعل السطر الأول عنوان الفصل بصيغة `# عنوان الفصل`.
5. اكتب الفقرات بعدها، ويمكن استخدام `### عنوان مشهد` للعناوين الداخلية.
6. احفظ الملف واعمل Commit إلى فرع `main`.

سيقوم GitHub Actions تلقائيًا بتوليد صفحة HTML مستقلة للفصل، وتحديث الفهرس وعدد الفصول وروابط السابق والتالي وبيانات المكتبة. لا تعدّل صفحات HTML الناتجة يدويًا؛ فهي ملفات مولّدة ويمكن استبدالها في البناء التالي.

## إضافة رواية جديدة

- أضف مجلدًا داخل `content/novels/<slug>/chapters/`.
- أضف بيانات الرواية إلى `content/novels.json` (العنوان، المؤلف، التصنيفات، المقدمة، ومسارات المحتوى والإخراج).
- استخدم بادئة ملفات فصول فريدة في `chapterPrefix`.
- أضف بطاقة الغلاف/الأيقونة إلى نظام CSS عند الحاجة فقط؛ القالب وبنية القراءة مشتركان تلقائيًا.

## البناء محليًا

يتطلب Node.js 22 أو أحدث، ولا يحتاج إلى تثبيت حزم:

```bash
node scripts/build.mjs
```

## البنية

- `content/novels.json`: بيانات الروايات والمقدمات.
- `content/novels/*/chapters/*.md`: النصوص الأصلية للفصول.
- `scripts/build.mjs`: مولّد الصفحات والقوالب المشتركة.
- `style.css`: التصميم العام وقالب القراءة.
- `.github/workflows/build-and-publish.yml`: البناء الآلي عند الدفع إلى main.
- `catalog.json`: فهرس مولّد تستخدمه الصفحة الرئيسية لعرض الروايات وعدد الفصول.

الصفحات المنشورة ملفات HTML مستقلة؛ لذلك يعمل الموقع على GitHub Pages دون تشغيل JavaScript لبناء صفحات القارئ داخل المتصفح.
